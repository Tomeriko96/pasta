## Why This Model Works

### 1. Differentiates from Competitors
- Bella Roma: Pure ingredients (boring)
- Buon Gusto: Bilingual practical (generic)
- Caffè Italia: Casual minimal (impersonal)
- **La Carbonara (NEW):** Context + Sensory + Ingredients (memorable)

### 2. Matches Local Winners
- Il Pacioccone: Uses this exact hybrid model, successfully
- La Cantina: Uses narrative + ingredient, popular with tourists
- Both prove it works in this neighborhood

### 3. Compact & Scannable
- Same length as competitors (15-18 words)
- More information density (herkomst + sensory + ingredients)
- No wasted words, no flowery nonsense

### 4. Natural Language (No LLM Giveaways)
- No em-dashes, no Oxford commas where weird
- No "vibrant" / "elevated" / "deconstructed" buzzwords
- No lists formatted like a menu description algorithm generated them
- Real, conversational tone that a human restaurant would write
